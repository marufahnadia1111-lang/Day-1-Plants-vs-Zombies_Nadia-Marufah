## Dokumentasi Kegiatan Workshop

### 1. Rangkuman Materi
* **Prompt Engineering:** Merupakan teknik menyusun perintah atau instruksi untuk AI supaya hasil yang diberikan sesuai dengan kebutuhan pengguna. Dalam membuat prompt yang efektif, terdapat empat komponen yang perlu diperhatikan, yaitu **Role** untuk menentukan peran AI, **Task** untuk menjelaskan pekerjaan yang harus dilakukan, **Context** sebagai informasi pendukung, dan **Format** untuk menentukan bentuk hasil yang diharapkan.
* **Git dan GitHub:** Git merupakan sistem pengontrol versi terdistribusi (*Distributed Version Control System*) yang digunakan secara lokal untuk mencatat setiap perubahan kode dan dikembangkan oleh Linus Torvalds. Sementara itu, GitHub merupakan layanan berbasis web yang memungkinkan pengguna menyimpan repository secara online sekaligus bekerja sama dengan pengguna lain.
* **Git Workflow:** Proses pengelolaan perubahan dalam Git terdiri dari beberapa tahapan, yaitu *Working Directory*, *Staging Area*, dan *.git Directory* atau Repository. Perpindahan perubahan dilakukan menggunakan perintah seperti `git add` dan `git commit`.
* **Perintah Penting Git & GitHub:**
  * `git init` digunakan untuk membuat atau menginisialisasi repository Git.
  * `git add .` berfungsi untuk memasukkan seluruh perubahan file ke dalam *staging area*.
  * `git commit -m "pesan"` digunakan untuk menyimpan perubahan dengan memberikan keterangan atau pesan tertentu.
  * `git push origin main` berfungsi mengunggah perubahan dari repository lokal menuju repository GitHub.

### 2. Poin-Poin Penting / Pengetahuan Baru
* Mengetahui bahwa penyusunan prompt yang jelas, terarah, dan disertai informasi pendukung dapat memengaruhi kualitas jawaban AI. Hal ini juga diterapkan dalam pembuatan proyek seperti *Student Task Planner* agar hasil kode yang diperoleh lebih sesuai dengan kebutuhan dan mengurangi kemungkinan kesalahan.
* Mendapatkan pemahaman mengenai penggunaan SSH Key melalui perintah `ssh-keygen` sebagai salah satu metode autentikasi. Selain itu, mempelajari bagaimana menghubungkan terminal, Visual Studio Code, dan GitHub untuk mempermudah proses pengelolaan repository.

### 3. Pendapat Pribadi (Refleksi Day 1)
Kegiatan workshop pada hari pertama memberikan pemahaman dan pengalaman baru mengenai penggunaan kecerdasan buatan serta pengelolaan proyek menggunakan Git dan GitHub. Dari materi yang disampaikan, saya memahami bahwa pemberian instruksi yang tepat kepada AI dapat membantu menghasilkan solusi yang lebih sesuai dengan kebutuhan. Selain itu, materi mengenai *Version Control* juga memberikan gambaran tentang cara mengelola perubahan kode dengan lebih rapi dan terorganisasi. Pengetahuan yang diperoleh melalui kegiatan ini tentunya dapat menjadi bekal untuk mengembangkan berbagai proyek aplikasi pada tahap pembelajaran berikutnya.erja *version control* sangat membantu dalam mempersiapkan diri menghadapi proyek-proyek pengembangan aplikasi ke depannya.
